# Larkfield brand

Larkfield Home & Apparel is a fictitious retailer of kitchenware and clothing, made up for this
demo. These files let the board, the screenshots and any slides show one consistent brand.

| File | Use |
|---|---|
| `larkfield-mark.svg` | The mark alone: favicons, avatars, small spaces. |
| `larkfield-lockup.svg` | Mark and wordmark on light backgrounds. |
| `larkfield-lockup-dark.svg` | Mark and wordmark on dark backgrounds, as on the board. |

The wordmark text is converted to outlines, so the files need no fonts installed.

## Colors

| Name | Hex | Role |
|---|---|---|
| Meadow | `#2F5D4F` | The mark's tile; the tagline on light backgrounds. |
| Lark | `#E0A947` | The sun; the tagline on dark backgrounds. |
| Linen | `#F4EEDF` | Field lines; the wordmark on dark backgrounds. |
| Ink | `#1E2B27` | The wordmark on light backgrounds. |

## Type

- Wordmark: DM Serif Display.
- Tagline and the board's interface: Barlow.

Both are under the SIL Open Font License, from Google Fonts.

## Usage

- Leave clear space around the lockup of at least half the mark's height.
- Don't recolor the mark, stretch it, or set the wordmark in another typeface.
- The board keeps its own red accent; the brand appears in the header and the favicon only.
